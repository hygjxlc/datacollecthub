# 设备台账与事件记录（铭牌/测点字典/事件）设计

> 状态：设计已获用户批准（4 节展示逐节确认）
> 日期：2026-08-28

## 目标

为 DataCollectHub 增加三类收集阶段关键信息的记录能力，并使其随下载/集成导出联动：

1. **事件/故障记录**：何时、何设备、发生了什么——构建多模态事件组数据集的锚点
2. **测点字典**：SCADA 通道号/点号 → 物理量、单位、缩放系数
3. **铭牌与台账参数**：设备铭牌数据，用于物理规则库 50 条校验规则参数标定

**核心原则**：
- 三类信息均为**可选录入**（不阻断上传/建批次流程）
- **半约束**：仅前端在上传 SCADA 模态文件时提示"该设备未配置测点字典"（可跳过）
- **联动导出**：下载包与集成接口的元数据 JSON **有则附带、无则 null**，不阻断

## 数据模型

### nameplates 设备铭牌台账（每设备一条，同单位 device_no 唯一）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | String(36) PK | uuid |
| organization_id | FK → organization.id | 单位隔离 |
| device_no | String(64) | 设备编号，同单位唯一（与批次/文件 device_no 一致） |
| device_model | String(128) | 设备型号 |
| rated_power | Float | 额定功率（kW） |
| rated_wind_speed | Float | 额定风速（m/s） |
| rotor_diameter | Float | 转子直径（m） |
| hub_height | Float | 轮毂高度（m） |
| bearing_model | String(128) | 轴承型号 |
| gearbox_ratio | Float | 齿轮箱速比 |
| generator_model | String(128) | 发电机型号 |
| manufacturer | String(128) | 制造商 |
| commission_date | String(10) | 投运日期（YYYY-MM-DD） |
| design_life_years | Int | 设计寿命（年） |
| extras | JSON | 其他参数（键值对，供规则库扩展） |
| creator_id / created_at / updated_at | — | 录入人 / 时间戳 |

唯一约束：`(organization_id, device_no)`。

### point_dicts 测点字典（每设备多条，(device_no, channel_no) 唯一）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | String(36) PK | uuid |
| organization_id | FK | 单位隔离 |
| device_no | String(64) | 设备编号 |
| channel_no | String(32) | 通道号/点号（如 CH1、SCADA_037） |
| name | String(128) | 物理量名称（如"齿轮箱轴承温度"） |
| unit | String(32) | 单位（℃、kW、rpm、Hz） |
| scale_slope | Float | 缩放系数 slope（physical = raw * slope + offset） |
| scale_offset | Float | 缩放系数 offset |
| data_type | String(16) | float / int / string / boolean |
| range_min / range_max | Float | 量程（可选，异常检测用） |
| description | String(512) | 备注 |
| created_at / updated_at | — | 时间戳 |

唯一约束：`(organization_id, device_no, channel_no)`。
第一版仅单条 CRUD，不做 CSV 批量导入（后续需要再加）。

### events 事件记录 + event_files 关联表

**events**

| 字段 | 类型 | 说明 |
|---|---|---|
| id | String(36) PK | uuid |
| organization_id | FK | 单位隔离 |
| event_time | String(32) | 事件时间（设备本地时间，格式同 DataFile.start_time） |
| timezone | String(32) | 时区（默认 +08:00） |
| device_no | String(64) | 事件设备 |
| event_type | String(128) | 事件类型（层级字符串，如"齿轮箱/轴承/磨损"） |
| severity | String(16) | 严重级别：报警 / 故障 / 事故（中文值） |
| description | Text | 事件描述（长文本） |
| creator_id / created_at / updated_at | — | 录入人 / 时间戳 |

**event_files**（多对多关联，支持双向查询）

| 字段 | 类型 |
|---|---|
| event_id | FK → events.id（级联删除） |
| datafile_id | FK → data_file.id |
| (event_id, datafile_id) UNIQUE | — |

## 后端接口（三组 CRUD，按单位隔离，admin 全见）

**nameplates**：`GET /api/v1/nameplates`（列表）、`GET /api/v1/nameplates/by-device/{device_no}`、`GET/PUT/DELETE /api/v1/nameplates/{id}`、`POST /api/v1/nameplates`

**point-dicts**：`GET /api/v1/point-dicts?device_no=`（列表按设备过滤）、`GET/PUT/DELETE /api/v1/point-dicts/{id}`、`POST /api/v1/point-dicts`

**events**：`GET /api/v1/events?device_no=&start=&end=&severity=`（组合过滤）、`GET/PUT/DELETE /api/v1/events/{id}`、`POST /api/v1/events`（body 含 `related_file_ids: [id,...]`，写入 event_files）

错误语义：
- 越权/不存在 → 404（跨单位隐藏，与现有一致）
- 唯一冲突（同单位同设备铭牌 / 同设备同通道号 / 事件重复关联）→ 409
- 删除事件 → event_files 级联清理

## 半约束（前端软校验，后端零阻断）

上传页面选择 SCADA 模态文件后、发起上传前：
1. 调 `GET /point-dicts?device_no={批次 device_no}`
2. 0 条 → `ElMessageBox.confirm`：「当前设备 {device_no} 未配置测点字典，上传的 SCADA 通道号将无法被下游解释。是否继续上传？」
   - 「继续上传」→ 跳过，继续上传
   - 「去配置」→ 跳转 `/devices/point-dicts`，取消本次上传
3. 非 SCADA 模态不检查

## 联动导出（下载/集成）

下载包每文件元数据 JSON 追加 3 个字段（有则附带，无则 null/空数组）：

```json
{
  "file": { "...": "不变" },
  "batch": { "...": "不变" },
  "nameplate": { "...": "该设备铭牌，无则 null" },
  "point_dicts": [ "...该设备测点字典列表，无则 []" ],
  "related_events": [ "...关联到该文件的事件列表，无则 []" ]
}
```

- 认证下载 `POST /files/batch-download` 与集成导出 `GET /integration/files/{id}/download` 均生效（复用 build_file_metadata）
- 集成查询 `GET /integration/files/{file_id}` 的 metadata 同样追加 3 字段
- zip 文件夹结构不变（`<stem>/原始文件 + <文件名>.json`）

## 前端

- AppLayout 侧边栏新增「设备台账」菜单 → 单页 3 Tab：铭牌台账 / 测点字典 / 事件记录
- Tab1 铭牌：表格（设备编号、型号、额定功率、转子直径、投运日期、操作）+ 对话框表单（12 字段 + extras JSON 文本框，非法 JSON 报错）；提示「设备编号需与批次/文件中 device_no 一致」
- Tab2 测点字典：设备选择器（本单位已出现 device_no）+ 表格（通道号、名称、单位、slope、offset、数据类型、操作）+ 对话框表单；重复通道号后端 409 提示
- Tab3 事件：筛选（设备/时间范围/级别）+ 表格（事件时间、设备、类型、级别 tag 色、描述摘要、关联文件数、操作）+ 对话框（时间选择器、层级类型可自由输入、级别下拉中文、关联文件多选=该设备已上传文件可搜索）
- 批次详情页设备编号旁完整率图标：铭牌已录/未录、测点字典已录/未录（有 SCADA 文件时）
